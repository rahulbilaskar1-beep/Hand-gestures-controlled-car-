# Self-Balancing Robot

## Overview
Two-wheeled robot that balances itself using an MPU6050 and PID control.

## Components
- Arduino Uno, MPU6050, L298N, DC motors

## How it works
Reads tilt angle, calculates error, and a PID loop drives the motors to stay upright.
